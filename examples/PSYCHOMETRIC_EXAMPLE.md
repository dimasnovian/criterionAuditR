# Hypothetical questionnaire scoring audit

This example demonstrates an applied measurement workflow using entirely generated responses. The facet labels self-regulation and persistence are teaching labels. No instrument was administered, no item content was validated, and no claim about human behavior is supported by these responses. The hypothetical scoring key does not establish that a total score is substantively appropriate for every two-facet instrument.

## Generate and audit

```sh
Rscript run_psychometric_example.R
Rscript run_psychometric_example.R outputs/another_run
```

The script uses base R with seed 20261106 and n=2,000. It draws two standard normal latent variables with correlation .35. Four item response variables depend on each facet, with loading .70 and independent standard normal errors with coefficient sqrt(1-.70^2). The fourth continuous response is negated before discretization to represent a negatively keyed item. Thresholds -1, -.3, .3, and 1 produce five ordered categories. The scoring key transforms q4_raw to q4_key=6-q4_raw. These are ordinal responses generated by thresholding normal variables, not parameters estimated from an instrument.

Subscale A sums q1, q2, q3, and q4_key; subscale B sums q5 to q8. The illustrative total is A+B, ranging from 8 to 40. The binary band is total>=24. The value 24 is an arbitrary teaching threshold with no clinical, diagnostic, or established screening meaning. The total is also rescaled to 0 to 100. All these rules are explicit in `psychometric_rules.R` and can be inspected or replaced by a researcher's independently justified scoring key.

The graph for criterion total flags five specified predictors as construction components, two as descendants, and external_noise as not flagged. Auditing subscale B against subscale A yields no declared overlap, even though the two facets were generated to correlate. An absence of declared overlap does not imply statistical independence. The audit does not infer graph edges from correlations.

## Fault controls and expected results

The clean data evaluate all six rules over 2,000 profiles with zero mismatches. A copy omits reverse scoring in 20 rows whose raw item is not the midpoint, propagates that key through the downstream score calculations, then changes 15 disjoint total-score entries and flips 10 disjoint band labels. The expected audit counts are 20 for q4_key, 15 for total, and 10 for score_band; the other three equations remain internally consistent. Each check compares a stored output with its declared direct-parent inputs, rather than attributing every downstream discrepancy to a root cause automatically. The seeded corruption is an explicit controlled intervention, not the observed prevalence of errors in real questionnaires.

The subscale A correlation with its inclusive total is 0.7850655; with nonoverlapping subscale B it is 0.2524326. Both share the simulated latent association, while only the first comparison includes A on both sides. These two correlations have different definitions and must not be interpreted as interchangeable estimates of validity.

The separate ordinal null control uses seed 20261107, 5,000 profiles, and five independent uniform integer responses from 1 to 5. It gives item-total correlations from 0.4346255 to 0.4602663 and item-rest correlations from -0.004573489 to 0.011864448. For equally variable independent items, the population item-total correlation is 1/sqrt(5), whereas the item-rest correlation is zero. The control illustrates part-whole association without a common trait.

Pearson correlations are used here to expose algebraic inclusion and to match `ca_partwhole`; no factor model, polychoric correlation model, or reliability estimator is fitted. Item-rest correlation is an established diagnostic. Overlap can be appropriate in item analysis or scoring-rule reconstruction; it needs scrutiny if presented as independent evidence of criterion prediction. The program does not assess content validity, construct validity, dimensionality, measurement invariance, or clinical utility.

## Output files

`simulated_questionnaire.csv` contains all raw/keyed items, both subscales, total, band, rescaled total, and independent noise. `independent_ordinal_responses.csv` contains the null responses. The clean and injected directories contain aggregate rule checks, predictor flags, graph edges, and RDS audit objects. Separate CSV files record planted fault counts, item and subscale correlations, and six integration checks. `sessionInfo.txt` records the executed R environment. Existing files in the chosen output directory are overwritten when the script is rerun.

The graph and checks come from core program version 0.1.0. The new executable example adds no core API and does not convert the distribution into an installable package. Original generated inputs and code are MIT licensed.
