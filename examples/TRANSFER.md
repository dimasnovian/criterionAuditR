# Audit across three generated scoring designs

Run `Rscript run_psychometric_example.R` and then `Rscript run_score_transfer.R` from the project root. The latter accepts a single optional output directory. It writes generated inputs, evaluated denominators, fault counts, and criterion paths.

| Design | Input | Scoring | Detected / planted |
| --- | ---: | --- | ---: |
| Ordinal questionnaire | 2,000 simulated profiles | Reverse-keyed item, subscale sums, total, and threshold label | 45/45 |
| Dichotomous ability | 1,600 simulated profiles | Four domain sums, total, scale conversion, and conjunctive classification | 23/23 |
| Weighted tasks | 6,048 exhaustive generated combinations | Weighted index, rounding, and threshold label | 25/25 |

## Input generation

The [ordinal questionnaire](PSYCHOMETRIC_EXAMPLE.md) is generated by `run_psychometric_example.R`. Its output is `outputs/psychometric_demo/simulated_questionnaire.csv`.

The ability simulation uses seed 20261107. It generates a standard-normal general factor and four independent standard-normal domain factors for each hypothetical profile. Sixteen Bernoulli items use the logistic inverse link with loadings 0.85 and 0.55 on the general and applicable domain factors. Item difficulties are equally spaced from −1.2 to 1.2. The script marks one item missing in each of 240 distinct randomly selected profiles, with 15 omissions per item. It writes `outputs/score_transfer/simulated_ability_items.csv`.

The weighted example enumerates the Cartesian product of task values 0–17, 0–13, and 0–23. Its inputs are in `outputs/score_transfer/weighted_task_grid.csv`. An integer-rational reference checks the reported index rounded to one decimal place.

## Verification

All 64,576 evaluable values across 20 clean rules agreed. The ability total and classification evaluated 1,360 complete profiles. The audit recovered all 93 planted discrepancies and verified that each intended row group failed its specified rule. Thresholding before rounding changed 4 weighted labels. See `outputs/score_transfer/rule_checks.csv` and `rounding_boundary.csv`.

The scoring thresholds and item parameters are illustrative. The checks establish recovery for the specified test cases and scoring rules. The simulation supplies no evidence about validity of an instrument or performance on respondent data.
