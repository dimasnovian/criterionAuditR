# Auditing three score constructions

The same audit interface was applied to an ordinal questionnaire, a dichotomous ability test, and a weighted index. The cases vary the input type, scoring operations, classification rule, and presence of missing responses. Each uses an explicit scoring specification and a clean baseline, then introduces faults at specified stages.

| Design | Data | Operations | Planted and detected discrepancies |
| --- | --- | --- | ---: |
| Ordinal questionnaire | 2,000 simulated eight-item profiles | Reverse key, nested sums, rescaling, and a single cutoff | 45 of 45 |
| Dichotomous ability test | 1,525 published profiles on 16 scored items | Four domain sums, total, and a rule requiring both a total and a domain cutoff | 23 of 23 |
| Weighted task index | 6,048 combinations of three bounded integer scores | Standardization, unequal weighting, rounding to tenths, and thresholding | 25 of 25 |

The clean baselines gave zero disagreements among 63,639 evaluated rule values. The fault checks verified the rule and rows assigned to each planted discrepancy. The design counts apply to the tested scoring specifications. They do not estimate performance for unobserved faults or determine the psychometric validity of a score.

## Published ability responses

The `ability` dataset in `psychTools` includes 16 publicly distributed scored items from the SAPA ability example. The script selects item columns only and exports aggregate checks and declared paths. Data can be obtained separately through the [psychTools reference and package](https://search.r-project.org/CRAN/refmans/psychTools/html/ability.html). The recorded run used [ability.rda from version 2.6.4](https://github.com/cran/psychTools/blob/7dc591f8ac11c0ef1764cf853f3065aa60653d09/data/ability.rda).

The example forms reasoning, letter-series, matrix, and rotation sums from four items each. It evaluates each sum when all four items are present, and the total and classification when all 16 items are present. The demonstration label requires a total of at least 10 and a reasoning score of at least 2. The two cutoffs are illustrative and do not define an ICAR assessment standard. Domain rules evaluated 1,380, 1,359, 1,419, and 1,401 profiles, respectively. The total and decision each evaluated 1,248 of 1,525 profiles. The remaining 277 profiles were unevaluable for those two equations under the specified complete-response policy.

The controlled faulty copy introduces 11 reasoning-score discrepancies, seven total-score discrepancies, and five label discrepancies at the inclusive boundary. Upstream changes are propagated to later stored scores before injecting later faults, so the audit distinguishes a locally inconsistent calculation from the consistent propagation of an earlier error. The path `reason.4 -> reasoning -> decision` records how an item participates in the illustrative label. A scaled total shares a construction ancestor with that label.

## Weighted rounded index

The finite grid crosses accuracy 0–17, recall 0–13, and fluency 0–23. The three scores are scaled to 0–100 and combined with weights .47, .31, and .22. The reported index is rounded to one decimal before the illustrative cutoff of 60 is applied. A separate integer-rational formula constructs clean reference values for all combinations.

Four raw indices were below 60 but rounded to 60. Applying the cutoff early altered these four labels. The challenge also introduces 12 weighting discrepancies and nine rounding discrepancies at disjoint rows. The audit locates each at its declared stage. The full path from accuracy to the label includes normalization, weighting, and rounding. The raw-index label and the rounded-index label share a declared ancestor.

## Reproduce the results

Run the original simulation before the cross-design audit. The audit accepts an installed `psychTools` package or the pinned external data file. Both synthetic examples are generated by the scripts. The source file for the observed data is obtained independently.

```sh
Rscript run_psychometric_example.R
Rscript run_score_transfer.R
Rscript run_score_transfer.R outputs/score_transfer path/to/ability.rda
```

The recorded results are in `outputs/score_transfer/`. `design_summary.csv` summarizes designs. `rule_checks.csv` reports declared coverage, clean disagreements, and planted and detected counts. `criterion_paths.csv` gives the graph evidence. `rounding_boundary.csv` contains only the four simulated task combinations at the boundary. The `psych` and manual R comparison for the ordinal case is described in [COMPARISON.md](COMPARISON.md).
